# Баланс и числовые константы

Все таблицы баланса — в секции КОНСТАНТЫ `rescue-hq.html` (и пара в СОСТОЯНИЕ). Меняйте числа
здесь — и обязательно прогоняйте харнесс ([testing.md](testing.md)), он ловит и падения, и
регресс проходимости.

## Где что лежит

| Константа | Значение | Смысл |
|---|---|---|
| `W,H` / `HQ` | 12,12 / (5,11) | размер карты / штаб |
| `TERR` | — | типы местности (имя) |
| `SMOD[terrain][type]` | множители | эффективность поиска по местности×типу |
| `TMOD[terrain][type]` | множители | множитель времени в пути |
| `NIGHT[type]` | 0.5–0.85 | ночной штраф к поиску |
| `WEATHER[w].mod/.drain` | — | погодные множители поиска / доп. падение сил |
| `TYPES[type]` | — | `power, cellMin, fatS, fatT, unlock, cost, gen` |
| `TENTCAP` | [0,3,5,7] | вместимость отрядов по уровню шатра |
| `MISSCAP` | [2,3,4,6] | групп в поле по уровню радио |
| `RANGE` | [5,7,10,99] | радиус связи (чебышёв) по уровню радио |
| `EXPT` | [0,20,12,6] | минут на экспертизу по уровню картографа |
| `EXPS` | [0,1,2,3] | параллельных экспертиз |
| `EXPCOST` / `EXPREWARD` | 35 / 40 | цена экспертизы / возврат за верную догадку |
| `RESTM` | [1,1.7,2.4,3.2] | множитель отдыха по уровню кухни |
| `BUILD[key].costs` | — | цены уровней построек |
| `TRAINCOST` / `TRAINTIME` | [0,0,120,200] / 90 | цена обучения до уровня / длительность |
| `drainBase` (в `tryGen`) | `100/(1600+150·dist(HQ,victim))` | скорость падения сил жертвы |
| пассивный доход (в `simMinute`) | `+0.55/мин` | пожертвования |

## Ключевые формулы
- Поиск/минуту: `eff = power · (1+0.3·(lvl-1)) · SMOD · WEATHER.mod · NIGHT? · fatEff`,
  где `fatEff = 1 − 0.6·(fatigue/100)^1.5`.
- Вероятность находки/минуту: `1 − exp(−eff · vis · 0.03 · dogBonus)` (`vis`=наземная,
  для дрона `air`; `dogBonus`=1.5 у кинолога на клетке маршрута).
- Время пути: `dist(HQ,cell) · cellMin · TMOD · (1−0.15·(lvl-1))`, ×1.25 при усталости >70.
- Падение сил: `drainBase`, ×1.2 ночью, + `WEATHER.drain`.

## Как настроен баланс (ориентиры)
- Жизнь жертвы масштабируется от дистанции: дальние пропавшие живут дольше — так далёкие карты не
  становятся автоматически непроходимыми. Диапазон ≈ 1750–3400 симминут.
- Лагерь теперь в 2–3 клетках от ТПК (см. systems.md), поэтому маршруты короче. Из-за этого стартовый
  радиус связи ужат до 5 (иначе покрывал бы всю карту), а база жизни жертвы снижена (1900→1600), чтобы
  сохранить сложность. При радиусе 5 тропа покрыта в среднем на ~84%, полностью лишь у ~53% карт —
  почти половине карт нужен апгрейд радиостанции, чтобы дотянуться до дальнего конца тропы.
- Экспертиза платная и с возвратом за верную догадку — чтобы игрок читал приметы, а не слал всё
  подряд «на авось».

## Результаты прогонов (headless-харнесс)
На момент последней проверки (см. `docs/testing.md`, `harness.js`):
- **Генерация** (5000 попыток): вырожденные ~10%/попытку, но с 200 ретраями «мёртвая» карта
  практически невозможна; артефактов всегда ≥4.
- **Авто-игрок**: компетентная стратегия выигрывает ~68–72% дел (остаток сил ~48%), наивная —
  0%. **0 исключений** на сотнях партий по ~2500 минут.
- **Кампания**: перенос построек/ростера/обучения, сброс усталости, новая локация, свежий бюджет,
  запись/очистка `localStorage` — все проверки проходят.

Живой человек играет лучше механической стратегии, так что ~70% baseline — комфортный уровень
сложности: выиграть реально, но зевать нельзя.
