# Ассеты (иконки)

Все иконки — SVG в папке `images/` рядом с `rescue-hq.html`. Игра ссылается на них относительными
путями через CSS-фон и `<img>`. Без папки игра работает — клетки просто остаются цветными без
символов (никаких ошибок).

## Что где лежит

```
images/
  forest.svg  dense.svg  meadow.svg  marsh.svg  hills.svg   ← топознаки местности (в корне)
  units/   foot.svg  dog.svg  atv.svg  drone.svg
  hq/      tent.svg  radio.svg  carto.svg  rest.svg  train.svg
  markers/ pin.svg   victim.svg  trail.svg
```

## Топознаки местности (углы клеток)
- Источник: набор условных знаков QGIS `D:\Downloads\Symbols_ru` (лицензия — в архиве).
  Взяты: `leafy` (лес), `pinaceae` (чаща/ель), `grassy-high-fill` (поляна), `swamp-fill` (болото),
  `mound` (холмы). Штрихи были чёрные/цветные — при копировании **перекрашены в светлые тона**
  (иначе не видны на тёмных клетках) и им добавлен `viewBox`.
- Подключение: элемент `.ter` в каждой клетке, фон задаётся CSS по классу местности:
  `.t-forest .ter{background-image:url(images/forest.svg)}` и т.д. Полупрозрачные (opacity ~0.5–0.6),
  в верхнем левом углу. Озеро/лагерь символа не имеют.
- В легенде (`#mapHdr`) те же символы наложены на цветные образцы `.sw`.

## Иконки юнитов, построек, маркеров (нарисованы вручную)
- В библиотеке QGIS нет квадроциклов/дронов/собак — эти иконки нарисованы как простые векторы 24×24
  под тёмный фон (монохром, светлый цвет; палатка — янтарная, булавка — красная, жертва — зелёная).
- **Юниты** (`TYPES[type].svg`): подставляются на карту в `unitPositions()` как `<img class="ui">`
  в слое `.uu` (несколько отрядов в одной клетке стопкой).
- **Маркеры карты** (`updateMap`, слой `.mk`): база → `hq/tent.svg`, ТПК → `markers/pin.svg`
  (с классом `pulse`), след пропавшего в конце дела → `markers/trail.svg` (тёплый золотой цвет,
  чтобы отличаться от кремовых топознаков местности), жертва → `markers/victim.svg`. Стрелки
  направления улик (`↑ ◎ •`) остаются текстовыми глифами.
- У всех карточных `<img>` — `filter: drop-shadow(...)` для читаемости над разной местностью.

## Что пока НЕ на SVG (используют эмодзи)
Панели/журнал/тосты/кнопки по-прежнему используют эмодзи (`TYPES.icon`, `BUILD.icon`): заголовки
карточек в «Штаб»/«Отряды», строки в панели квадрата, тексты логов. Эмодзи в тексте — это нормально
и читаемо. SVG-файлы построек (`hq/*.svg`) уже есть — при желании легко подставить и в карточки.

## Как добавить/заменить иконку
1. Положить SVG в нужную подпапку `images/…` (24×24 `viewBox`, светлый цвет под тёмный фон,
   без внешних ссылок — самодостаточный файл).
2. Для юнита — прописать путь в `TYPES[type].svg`. Для маркера — в `updateMap`. Для местности —
   добавить CSS-правило `.t-<terrain> .ter{background-image:url(...)}` и образец в легенде.
3. Проверить рендер скриншотом через headless Chrome (см. [testing.md](testing.md)).

## Проверка иконок без игры
Готовый приём — собрать HTML-монтаж со всеми SVG на тёмном фоне и отрендерить headless-хромом
(так проверяли этот набор). Подробности и команда — в [testing.md](testing.md).
