# Документация «Оперативный штаб · Поиск»

Описание всех систем игры. **Актуальная кодовая база — Svelte-приложение в корне репозитория** (см.
`README.md`); однофайловый `rescue-hq.html` — легаси-референс. Движок в `src/engine/*`
портирован из легаси дословно, поэтому разделы про **системы, баланс и числа ниже актуальны и для
новой версии** (константы теперь в `src/engine/constants.ts`). Разделы про архитектуру/рендер
описывают легаси-подход; в Svelte-версии ручной диффинг заменён реактивностью — см. `README.md`.

## Одна страница про игру

Пропал человек. У игрока есть штаб (лагерь в нижней части карты 12×12) и пара пеших отрядов.
Игрок кликает квадрат, выбирает отряды и длительность осмотра — отряд **доходит → разведывает →
возвращается** с находками. Находки бывают настоящими (артефакты с маршрута пропавшего) и мусором;
игрок сам сверяет их с приметами из «Дела» и решает, куда вести поиск. Настоящие улики дают
направление и стягивают район вокруг пропавшего. Развитие штаба (постройки, наём, обучение) и сами
отряды **сохраняются между делами** — это кампания. Время ограничено: состояние пропавшего падает,
на нуле — проигрыш.
