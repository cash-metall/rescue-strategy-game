# Кампания (мета-прогрессия)

Штаб и команды переносятся между делами. Каждое новое дело — свежая карта, новый пропавший и новый
бюджет, но прежний уровень развития. Так обучение отрядов имеет смысл: оно окупается в будущем.

## Что переносится, а что нет

| Переносится (в `campaign`) | Сбрасывается на каждое дело |
|---|---|
| Уровни всех построек (`buildings`) | Карта, пропавший, маршрут, улики, журнал |
| Ростер отрядов: `type`, `name`, `level` | Усталость и статус отрядов (все `idle`, `fatigue:0`) |
| Счётчики нанятых (`nameCnt`) — нумерация имён | Бюджет (`funds` = 250) |
| Статистика (`stats.won` / `stats.lost`) | Погода, время (`t=0`), активные экспертизы |

## Формат сохранения

`localStorage`, ключ `SAVE_KEY = 'rescueHQ.campaign.v1'`. Объект:
```js
{
  buildings: {tent, radio, carto, rest, train},   // числа-уровни
  roster:    [{type, name, level}, …],             // команды
  nameCnt:   {foot, dog, atv, drone},              // для продолжения нумерации при найме
  stats:     {won, lost}
}
```
Дефолт (первый запуск / после сброса) — `DEFAULT_CAMPAIGN()`: шатёр ур.1, две пешие группы
«Лиса-1»/«Лиса-2», статистика 0/0.

## Функции

- `loadCampaign()` — читает и валидирует сохранение (`normalizeCampaign`: чинит битые/чужие поля,
  клампит уровни, отбрасывает юнитов с неизвестным `type`); при отсутствии/ошибке → дефолт.
  Всё в `try/catch` — если `localStorage` недоступен (бывает на `file://` в некоторых сборках),
  игра всё равно работает, просто без сохранения между перезагрузками.
- `saveCampaign()` — собирает `campaign` из текущего `G` (постройки, ростер с актуальными уровнями,
  `nameCnt`, накопленную `stats`) и пишет в `localStorage`. Вызывается при: постройке (`actBuild`),
  найме (`actHire`), завершении обучения (`stepUnit`/train) и в конце дела (`endGame`).
- `resetCampaign()` — стирает сохранение и ставит дефолт. Дальше `startCase()` начинает первое дело.
- `startCase()` — генерирует новое дело из текущего `campaign` (кнопка «Следующее дело»).
- `doHardReset()` — `resetCampaign()` + `startCase()` (кнопка «Новая игра» с подтверждением
  `confirm()`).

## Важная оговорка

Сохраняется **уровень развития между делами**, а не снимок середины дела. Перезагрузка страницы
посреди активного поиска сохранит штаб и команды, но само текущее дело начнётся заново на новой
карте. Полноценный резюм середины дела (карта, улики, отряды в пути) намеренно не реализован —
это большой и хрупкий сериализатор состояния. См. [roadmap.md](roadmap.md).

## UI кампании
- Шапка: счётчик «спасено / дел».
- Кнопка ⚙ (шапка) → `showSettings()`: хроника, сводка построек и состава, «Новая игра».
- Экран конца дела (`endGame`): хроника + «Следующее дело →» + «Сбросить прогресс».
